Documentation lives in the `igvc-hub` Git repository.

## Local Development

1. Clone the repository.
2. Install dependencies with `npm install`.
3. Start the developmnet server with `npm run dev`.
4. Edit Markdown files in `src/content/docs/docs`.

Changes will automatically appear in your local preview (localhost link that appears after running `npm run dev`).
